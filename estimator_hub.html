📖 Connect Google Drive — One-time setup (~5 min)

Google needs to know which app is requesting access to your Drive. You'll create a free OAuth Client ID and paste it back here.

⚠ Important: This tool must be opened via http://localhost or a hosted URL — not file://. Run python3 -m http.server 8000 in the folder, then visit http://localhost:8000
1Create a Google Cloud project
Go to console.cloud.google.com/projectcreate → name it anything (e.g. "Estimator Hub") → Create.
2Enable the Google Drive API
In the same project, go to APIs & Services → Library → Google Drive API → click Enable.
3Configure OAuth consent screen
Go to APIs & Services → OAuth consent screen
• User type: External → Create
• App name: Estimator Hub, your email for support/developer contact
• Scopes: skip (we'll request at runtime)
• Test users: add your own Gmail address ← important
• Save and continue through all steps
4Create OAuth Client ID
Go to APIs & Services → Credentials
• Click + Create Credentials → OAuth client ID
• Application type: Web application
• Name: Estimator Hub Web
• Under Authorized JavaScript origins add: http://localhost:8000 (and any other URL where you'll open this — e.g. your GitHub Pages URL)
• Click Create
5Copy your Client ID
A popup shows your Client ID (looks like 123456789-abc...apps.googleusercontent.com). Copy it, paste into the field on the Settings page, and click Connect Google Drive.
✓Done. Your data will sync to a file called estimator-hub-data.json in your Google Drive root folder. You can move it anywhere — the app will find it by name.
